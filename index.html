这条滤镜的影调曲线

这个滤镜还没量过，需要一步标定

NP3 文件里只存了滤镜编号，没存曲线 —— 所以必须用这个滤镜实际处理一张图，才能量出它到底做了什么。整个过程只要一分钟，量一次以后这个滤镜就进库了。

第 1 步：拿一张标定图

这张图上半是 256 级灰阶、下半是 32 块色卡。程序知道它每个像素原本是多少，所以能直接从处理后的结果倒推出曲线。

下载标定图 → 放进 NX Studio，优化校准选这个滤镜，其余参数保持默认，导出 JPG（尺寸不要改，色彩空间选 sRGB）

第 2 步：把导出的图传回来

点这里选择，或把导出的图拖进来
先选一张图

存进存储卡

先下载文件，再手动拷到卡里的 NIKON\CUSTOMPC；用 Chrome / Edge 也可以直接选卡写入。

拷进机身之后

  1. 把存储卡插回机身，开机；
  2. 按 MENU → 拍摄菜单 → 管理优化校准；
  3. 选一个空槽位 → 「载入/保存」→「从存储卡载入」；
  4. 之后就能在「设定优化校准」里选它，跟内置的几个并列。

它做了什么：把 NP3 的参数按对应关系搬进 NCP，并用一条自定义曲线重建滤镜的影调与色彩倾向；写入前会做机身曲线预补偿（机身执行的是 C(H(x))，直接写目标曲线会整体偏暗）。

它会丢什么：NP3 里的「清晰度」「效果级别」「快速锐化」在 NCP 格式里没有对应位置，三项会丢失；锐化、对比度、亮度、饱和度、色相、调色可以保留或近似。这是格式差异，不是转换出错。

为什么需要「标定」：NP3 文件里只有一个 2 字节的底子编号，没有曲线。已量过的底子直接用库里现成的结果；没量过的只能拿标定图现场量一次。
